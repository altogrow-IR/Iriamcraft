# Iriamcraft

空に浮かぶ島に、自分だけの配信ワールドをつくる3D建築ゲーム。IRIAMの「キャラクターが集まり、交流する居場所」というコンセプトに着想を得た非公式ファンゲームです。IRIAM・Minecraftとの提携や公式サービスへの接続はありません。

## 遊べること

- 編集可能な浮島、スタジオ、配信ステージ、桜、ベンチ。
- 11種類のブロック、1個・3連・3×3の配置、4種類の設計図。
- 指で場所を選び、大きな配置ボタンで確定。「調整」を開くと矢印・高さ・配置形状・取り外しを使えます。
- 回転、ズーム、真上視点、昼夜切り替え、PNG撮影。
- 40操作までのUndo / Redo、ブラウザへの自動保存、JSONバックアップの書き出し・読み込み。
- 30秒のライブシミュレーション。建築数・素材の種類に応じた住人数とエール。住民10人×5コメントを4.5秒ごとにランダム表示し、島の素材・高さ・昼夜に合う内容を優先します。ライブ中は建築ツールを隠し、コメントも折りたためます。
- ブロックを置いたときの粒子演出、任意のWeb Audio効果音。

## 開発

Node.js 22.13以上（直接TypeScriptを実行するテストはNode 24推奨）。

```sh
npm ci
npm run dev -- --port 5188 --strictPort
npm test
npm run lint
npm run build
npm start
```

React 19 / TypeScript / Vite 8 / Three.js。3DはInstancedMeshで描画し、端末の描画倍率は1.75まで。静的サイトなのでアプリ自身のAPIキー・ログイン・サーバーは不要です。Sitesの非公開閲覧には所有者アカウントの認証が必要です。

Sites公式テンプレートを利用し、端末内で完結するゲーム向けにViteの静的出力へ設定しました。テンプレート由来のUI部品と依存は保持しています。未変更のUI部品・hooksはlint対象外です。React CompilerとNext.jsは使用しないため、それら専用のlint検査は適用しません。アプリ・ゲームロジックは型検査とlintを行います。

## 操作

| 操作               | スマホ                 | PC                             |
| ------------------ | ---------------------- | ------------------------------ |
| 配置する場所を選ぶ | 島をタップ             | 島をクリック                   |
| 回転               | 1本指ドラッグ          | 左ドラッグ                     |
| 移動               | 2本指ドラッグ          | 右ドラッグ                     |
| 拡大縮小           | ピンチ / ＋−           | ホイール / ＋−                 |
| 配置               | 「ここに置く」         | 同ボタン / Enter               |
| 微調整             | 下部の方向・高さボタン | 同ボタン / 矢印 / PageUp・Down |
| 戻す               | 戻すボタン             | Ctrl / Cmd + Z                 |

キーボードの配置・移動はボタン外にフォーカスがある場合に有効。初期の床面積は約2.5倍（761マス）。建築可能範囲はX/Zが−8192〜8192、高さ−8192〜8192。地続きの床・建造物はブロック上限まで上下左右に拡張できます。負の高さでは配置後に次の下段を選びます。調整の照準ボタンで選択位置を画面中央へ移動でき、下からの回転表示にも対応します。地下建築中・地下ブロックがある島では、装飾の岩底を非表示にします。ブロック上限6000。地面は取り外せません。赤いプレビューは置けない状態を表し、ボタン操作時に理由を表示します。ライブはゲーム内のNPCによる演出で、オンライン配信やマルチプレイではありません。

## 保存

`localStorage` の `iriamcraft-world-v1` に保存。保存形式はversion 1。読み込み時は座標・素材・重複・件数・進捗を検証します。JSONインポートはUndo可能。既存の島はそのまま保持し、設定の「保存した島の床を広げる」で建築物を保持したまま新しい初期サイズへ拡張できます（Undo可能）。ブラウザ間・端末間の自動同期はありません。破損データの検出時は最初の編集まで既存保存を上書きしません。ブラウザが保存を許可しない場合は設定からJSONをダウンロードしてください。

## 公開

`npm run build` の `dist` を静的ホスティングへ配置します。`base: './'` でリポジトリ名配下に対応。アプリは単一画面のためSPAリロード404対策は不要です。

GitHub Pages向けのワークフローを `.github/workflows/pages.yml` に同梱。Settings → Pages → SourceをGitHub Actionsにすると、`main` ブランチへのpushで自動公開されます。Actionsの「Deploy Iriamcraft」から手動実行することもできます。

対応ブラウザではWebMCPの `read_island` / `place_island_blocks` が利用できます。UIと同じ検証・履歴・保存処理を通ります。
