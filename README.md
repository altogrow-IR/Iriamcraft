# Iriamcraft

空に浮かぶ島に、自分だけの配信ワールドをつくる3D建築ゲーム。IRIAMの「キャラクターが集まり、交流する居場所」というコンセプトに着想を得た非公式ファンゲームです。IRIAM・Minecraftとの提携や公式サービスへの接続はありません。

## 遊べること

- 編集可能な浮島、スタジオ、配信ステージ、桜、ベンチ。
- 16色以上のカラー、7色のガラス／板ガラス、複数素材のハーフ・階段・柵・ドア・格子窓・屋根・ランプ・水源。1個・3連・3×3の配置、4種類の設計図。
- 素材はカテゴリ付きダイアログで選択。範囲消し、選択ブロック上のスワイプ90°回転、ドア開閉に対応。
- 指で場所を選び、大きな配置ボタンで確定。「調整」を開くと矢印・高さ・配置形状・取り外しを使えます。
- 回転、ズーム、真上視点、昼夜切り替え、PNG撮影。
- 40操作までのUndo / Redo、ブラウザへの自動保存、JSONバックアップの書き出し・読み込み。
- 30秒のライブシミュレーション。建築数・素材の種類に応じた住人数とエール。住民10人×5コメントを4.5秒ごとにランダム表示し、島の素材・高さ・昼夜に合う内容を優先します。ライブ中は建築ツールを隠し、コメントも折りたためます。
- ブロックを置いたときの粒子演出、任意のWeb Audio効果音。

## 開発

Node.js 22.13以上（直接TypeScriptを実行するテストはNode 24推奨）。

```sh
npm ci
npm run dev -- --port 5188 --strictPort
npm test
npm run lint
npm run build
npm start
```

React 19 / TypeScript / Vite 8 / Three.js。3DはInstancedMeshで描画し、端末の描画倍率は1.75まで。静的サイトなのでアプリ自身のAPIキー・ログイン・サーバーは不要です。Sitesの非公開閲覧には所有者アカウントの認証が必要です。

Sites公式テンプレートを利用し、端末内で完結するゲーム向けにViteの静的出力へ設定しました。テンプレート由来のUI部品と依存は保持しています。未変更のUI部品・hooksはlint対象外です。React CompilerとNext.jsは使用しないため、それら専用のlint検査は適用しません。アプリ・ゲームロジックは型検査とlintを行います。

## 操作

| 操作               | スマホ                 | PC                             |
| ------------------ | ---------------------- | ------------------------------ |
| 配置する場所を選ぶ | 島をタップ             | 島をクリック                   |
| 回転               | 1本指ドラッグ          | 左ドラッグ                     |
| 移動               | 2本指ドラッグ          | 右ドラッグ                     |
| 拡大縮小           | ピンチ / ＋−           | ホイール / ＋−                 |
| 配置               | 「ここに置く」         | 同ボタン / Enter               |
| 微調整             | 下部の方向・高さボタン | 同ボタン / 矢印 / PageUp・Down |
| 戻す               | 戻すボタン             | Ctrl / Cmd + Z                 |

キーボードの配置・移動はボタン外にフォーカスがある場合に有効。初期の床面積は約2.5倍（761マス）。建築可能範囲はX/Zが−8192〜8192、高さ−8192〜8192。地続きの床・建造物はこの座標範囲で上下左右に拡張できます。配置数の固定上限はありません（端末のメモリ・保存容量による制約はあります）。負の高さでは配置後に次の下段を選びます。調整の照準ボタンで選択位置を画面中央へ移動でき、下からの回転表示にも対応します。地下建築中・地下ブロックがある島では、装飾の岩底を非表示にします。地面も取り外し・交換できます。赤いプレビューは置けない状態を表し、ボタン操作時に理由を表示します。ライブはゲーム内のNPCによる演出で、オンライン配信やマルチプレイではありません。

## 保存

ワールドはIndexedDBの `iriamcraft` → `worlds` → `current` にversion 2で保存します。旧 `localStorage` の `iriamcraft-world-v1` は、読み込み→v2変換→書き込みトランザクション完了→読み戻し確認の順で移行し、旧データ自体は削除しません。v1の全ブロックはcube／回転0のまま維持します。IndexedDBが使えない場合も、読める旧データは表示してJSONで救出できます。

v2は素材・形状・90°回転・ドア開閉状態を持ちます。座標を安定した識別子として使い、ドアは上下2セルを占有します。JSONはv1/v2両対応で、形状・座標・重複占有・回転・進捗を検証します。読み込めない既存保存は編集するまで上書きしません。JSONインポートもUndo可能。40操作の履歴は追加／削除／変更ブロックと小さなメタデータだけを保持します。

ブラウザ間・端末間の自動同期はありません。保存失敗時は設定のJSONバックアップをご利用ください。

## 新しい建築操作

- 「素材と形を選ぶ」から基本／カラー／建築／ガラス／自然を切り替え、形と色を選びます。
- 配置済みブロックをタップで選択し、その上から左右にスワイプで水平90°回転。階段・ハーフ・屋根は上下スワイプでも回転します。4回で元の向き、ハーフは上下2回で上付きになります。
- 空いた場所からドラッグでカメラ回転、2本指で移動・ズーム。PCはRで水平、Shift+Rで上下回転。調整パネルにも回転ボタンがあります。
- 「範囲消し」→2点を選択→赤い直方体と件数を確認→「この範囲を消す」。1回のUndoで復元します。上側セルだけを含むドアも全体を消去します。
- ドアを選択して調整の「ドアを開く／閉める」。開閉状態も保存・Undo対象です。
- 調整の照準ボタンは、選んだ建築位置を画面中央へ移します。初回説明とヘルプにも記載しています。

## 描画とシミュレーション

- 16×16×16チャンク内で形状・素材をInstancedMeshにまとめます。変更チャンクと接続柵に影響する隣接チャンクだけを再生成し、境界球によるFrustum Cullingを使います。
- 柵は隣接する柵へ自動接続。ガラスは透過材質、形状ごとのRaycastとゴーストを使用します。
- 全ランプはemissive表示。近いランプのうちスマホ幅は8個、PC幅は12個をPointLightで照らします。配置数は制限しません。
- 水は水源だけを保存。編集時に影響範囲を調べ、必要なときだけWorker内のキューで派生セルを再計算します。下へ優先し、支えに届くと水平4方向へ水量7→1で広がります。最下部の建築物より下は空へ流れ出します。水面の透明度だけを軽く動かします。

## 検証

`npm test` は旧ルール・v1/v2互換・ドア占有・全形状配置/Raycast・回転制限・差分履歴・範囲消し・水・1万/2万/5万件・変更チャンク限定更新を確認します。

実ブラウザ検証は、別途インストール済みのPlaywrightとEdgeで実行できます。Playwrightを通常解決できない環境では `PLAYWRIGHT_MODULE` にパッケージのディレクトリを指定してください。実行前に `outputs` ディレクトリとテスト用サーバーを用意します。

```sh
# デフォルトURLは http://localhost:5188/
node tests/browser-check.mjs
# QA_URLで /Iriamcraft/ 等の本番サブパスを指定可能
```

詳細な実測と確認範囲は [QA.md](QA.md) を参照してください。

## 公開

`npm run build` の `dist` を静的ホスティングへ配置します。`base: './'` でリポジトリ名配下に対応。アプリは単一画面のためSPAリロード404対策は不要です。

GitHub Pages向けのワークフローを `.github/workflows/pages.yml` に同梱。Settings → Pages → SourceをGitHub Actionsにすると、`main` ブランチへのpushで自動公開されます。Actionsの「Deploy Iriamcraft」から手動実行することもできます。

対応ブラウザではWebMCPの `read_island` / `place_island_blocks` が利用できます。UIと同じ検証・履歴・保存処理を通ります。

## マイ設計図と内部ビュー

「調整 → 範囲選択」で2点を選び、「設計図として保存」から名前を付けます。地面は初期状態で除外し、チェックで含められます。設計図タブのおすすめ／マイ設計図から選択し、場所と向きを決めて「まとめて建てる」で配置します。管理メニューで名前変更・削除ができます。配置は1回のUndo／Redoで取り消し・復元できます。

DBスキーマはversion 2で、既存worldsを保持してblueprintsストアを追加します。ワールド形式のversion 2とは別のバージョンです。設計図は底面中央の整数基準点からの相対座標で保存し、水は水源のみ、ドアは閉じた状態を保存します。設計図保存の失敗はワールド保存に影響しません。島のJSONバックアップにはマイ設計図は含まれません。

新しい地面にはterrain属性を付け、通常配置にはfalseを付けます。属性のない旧データでは初期地面と座標・素材・形状が一致するブロックを地面として判定します。旧データで初期地面と同じ芝生を同じ場所に作り直した履歴は識別できないため、その場合は「地面ブロックも含める」を使ってください。

通常ズームは10倍まで。その後の追加ズーム操作で内部ビューに入り、ホイール／ピンチ／＋−でカメラが前後に移動します。内部のドラッグ回転はカメラ位置が中心で、右ドラッグ／2本指で平行移動できます。壁・ガラス・屋根・水・地面とのカメラ衝突はなく、近クリップは0.01です。「外観に戻る」でホーム視点へ戻ります。

追加ブラウザテスト: `node tests/blueprints-browser.mjs`（開発サーバー、PLAYWRIGHT_MODULEを指定）。実際のIndexedDB v1→v2移行、保存管理、配置履歴、ホイール／タッチ入力とカメラ座標を検証します。iPhone Safari／Android Chromeの実機検証は別途必要です。
